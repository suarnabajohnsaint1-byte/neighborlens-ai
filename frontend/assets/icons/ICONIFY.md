# NeighborLens interface icons

`frontend/styles/icons.css` is the local registry for shared interface icons. Its SVG paths come from Iconify's BoxIcons v2 collections `@iconify-json/bx@1.2.3` and `@iconify-json/bxs@1.2.3` (Boxicons 2.1.4, MIT). The [Boxicons license](BOXICONS-LICENSE.txt) applies to those paths.

Use the registered `bx` plus `bx-*` or `bxs-*` classes in interface markup. To add an icon, copy the matching Iconify SVG and add its encoded mask to the registry. Common GIS symbols reuse the same masks. NeighborLens brand artwork, custom damage symbols, and map assets are separate.

[Iconify icon data](https://iconify.design/docs/icons/icon-data.html)
